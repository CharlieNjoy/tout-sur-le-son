Dans une pièce fermée, certaines fréquences précises créent des ondes stationnaires entre les parois : ce sont les **modes propres** de la salle. Pour un mode axial (entre deux parois parallèles distantes de L), la fréquence fondamentale est f = c/(2L), puis ses multiples entiers.

Les modes **axiaux** (entre 2 parois) sont les plus énergétiques, car ils impliquent le moins de réflexions donc le moins de pertes ; viennent ensuite les modes **tangentiels** (4 parois) puis **obliques** (6 parois), plus faibles. C'est l'accumulation de modes graves mal répartis qui cause les creux et bosses de basses qu'on entend selon l'endroit où l'on se trouve dans une petite pièce.
