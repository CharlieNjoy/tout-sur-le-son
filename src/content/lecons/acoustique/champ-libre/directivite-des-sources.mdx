Une source réelle ne rayonne généralement pas de façon égale dans toutes les directions : le **facteur de directivité Q** indique de combien l'intensité dans l'axe principal dépasse l'intensité moyenne (Q = 1 pour une source omnidirectionnelle). L'**indice de directivité DI = 10·log(Q)** exprime le même rapport en dB.

Important : la directivité ne change pas la puissance totale rayonnée (ni donc le niveau moyen tous azimuts), elle la redistribue — plus de niveau dans l'axe, moins sur les côtés.
